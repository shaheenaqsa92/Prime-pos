# Prime POS

An AI-powered point-of-sale web app for a fictional accounting firm (Prime Accounting Services, PKR).

## Features
- Secure sign-in with Supabase Auth (forgot password included)
- New sale screen with 50 sample customers and 9 services
- Today dashboard: sales, bills, top customers and services
- 7-day and 6-month sales forecast with charts
- AI insights and finance chatbot (Supabase Edge Function + Groq)
- Sales data export to CSV

## Report
See Prime_POS_Report.pdf for the sales analysis and project report.

## Built with
HTML, CSS, JavaScript, Netlify, Supabase, Groq
